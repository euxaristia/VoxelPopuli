# Procedural mob artwork

All mob pixels are generated by `src/mob_visuals.rs` and
`src/mob_visuals/skins.rs`. The latter authors separate coat, face, muzzle,
hoof, horn and cloth patterns for the ten rebuilt animal models.
No source PNG sheets, encoded pixel copies or texture downloads are required.

Geometry and collision references are documented in
[the model notes](../../docs/mob-proportions.md). Colour palettes and markings
are original approximations, not byte-exact copies of the reference artwork.
